Project Title: PBL Real Life Application

1. Project Overview:
This project demonstrates the practical application of C programming through a structure-oriented persistent data management system.
The application is designed to manage student records efficiently using structures and file handling. Structures are used to organise student information, while file handling ensures that the stored records remain available even after the program is closed.
The system provides a simple interface through which users can log in, register and perform various operations related to student record management.

2. Main Functionalities:
The program includes the following features:

- Login and Registration: Allows users to register and log in to access the system.
- Add Student Records: Enables users to enter and save new student information.
- Search Student Records: Allows users to search for a particular student's information.
- Display Results: Retrieves and displays the stored student records.
- Update Records: Allows users to modify previously stored student information.
- Persistent Data Storage: Uses file handling to ensure that records are saved permanently and can be accessed later.
